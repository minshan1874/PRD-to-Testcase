# 牛小影 App「图生视频」功能需求文档（PRD）

版本：v0.9（评审稿）    负责人：产品组    日期：2026-09-05    状态：待评审

## 1. 概述

### 1.1 产品背景

牛小影是一款集 AI 视频增强与 AI 视频生成于一体的 App（iOS/Android，由深圳软牛科技出品，隶属 HitPaw 产品线）。当前 App 已具备视频修复、超清增强、AI 数字人、文生视频等能力。为完善 AI 生成矩阵、降低创作门槛，本版本新增「图生视频」能力：用户上传一张照片，输入文字指令并选择风格，AI 即可生成一段动态视频。

### 1.2 目标

- 让静态照片 3 步内（选图 → 输指令 → 选风格）生成动态视频，转化率达到「文生视频」入口的 1.2 倍以上（口径待定）。

- 生成成功率（已提交任务中产出可播放视频的比例）≥ 90%（口径待确认：是否包含审核驳回）。

- 不引入额外开发成本：复用现有账号体系、VIP/积分、作品管理等基础能力。

### 1.3 范围（In / Out of Scope）

**In Scope：**

- 移动端（iOS/Android）图生视频完整流程：选图、指令、风格、生成、预览、下载、分享、历史记录。

- 任务的排队/状态轮询/失败重试/取消；生成配额与权益（免费、积分、VIP）。

- 内容合规：AI 生成内容的审核与反馈。

**Out of Scope（本版本不做）：**

- 批量/多张图片输入；姿态/首帧驱动的高级控制；音轨生成与配音。

- Web/小程序端；视频帧级手动编辑；文生视频在本功能的整合。

## 2. 用户与场景

- **普通创作者**：上传宠物/自拍/风景照，输指令「让猫回头眨眼」，选「动漫」风格，得到 6 秒动态视频用于社交分享。

- **营销/内容用户**：用商品图加「展示产品 360 度旋转」指令生成短视频素材。

- **免费体验用户**：每日 1 次免费生成（次数待确认），不足时引导购买积分或开通 VIP。

## 3. 核心流程

```
入口 → 选图（相册/拍摄/裁剪） → 输入指令 → 选择风格 → 配置时长与比例 → 提交生成
     → 任务状态轮询（排队中/生成中/已完成/失败/已取消/审核中）
     → 成功：预览播放 →（下载 / 分享 / 保存到作品）
     → 失败：查看原因 →（重试消耗重新计算 / 修改参数重新提交）
```

## 4. 功能需求

### 4.1 入口与落地

- 首页 tab「AI 创作」下提供「图生视频」入口卡片；从「文生视频」页也有跨链接入口。

- 入口需展示当前剩余免费次数与提示（如「今日剩 0/1 次」）。

### 4.2 选图

- 支持从相册选择（多选单张）或调用相机拍摄。

- 支持对图片做基础裁剪（1:1、3:4、9:16、16:9、自由）。

- 图片格式：JPG/PNG/HEIC/WEBP；单张 ≤ 20MB；分辨率建议 ≥ 512×512（低于此值时提示「低清图片效果可能不佳，是否继续？」）。

- 含人脸图片需在提交前弹出「肖像与版权确认」弹窗（文案待法务确认）。

- 上传失败（损坏/超限/无权限）需明确原因提示。

### 4.3 指令输入

- 单行/多行输入框，字符上限 200（含中英文，按字符计）。

- 提供「灵感示例」折叠区：常见指令模板（如「镜头缓慢拉近」「人物眨眼微笑」）。

- 支持历史上传记录中的最近 5 条指令快速复用（去重）。

### 4.4 风格选择

- 内置风格卡片（横向滑动）：写实、动漫、3D 卡通、油画、水墨、赛博朋克、像素、玩具（具体风格清单需设计定稿）。

- 默认选中「写实」；风格随版本可下发更新（由服务端配置，客户端缓存）。

- 生成前展示风格名称与代表缩略图。

### 4.5 时长与比例

- 时长选项：4 秒 / 6 秒 / 10 秒（默认 6 秒）。

- 画面比例：与裁剪比例保持一致；首帧保持原图主体。（具体时长策略与算力成本相关，需技术评估后确认。）

### 4.6 提交与任务管理

- 提交前校验：是否已登录、免费次数/积分/VIP 是否足够、图片与参数是否合法。

- 提交后生成任务 ID，进入「我的生成」列表。

- 任务状态机：排队中 → 生成中 → 审核中（如开启审核）→ 已完成 / 失败 / 已取消。

- 客户端每 3 秒轮询一次（失败退避到 5 秒），任务最长等待 10 分钟（超时上限待确认）给出预估剩余时间。

- 支持取消排队中任务；生成中任务不支持取消。

- 失败原因分类：素材问题（图片太复杂/主体不清晰）、内容违规、服务超时、额度异常；各原因给出可操作提示。

### 4.7 结果与消费

- 生成成功后视频：时长按所选，分辨率 720P（输出分辨率待定，成本与质量权衡），带右下角产品水印（免费/VIP 策略待定）。

- 预览：自动播放、可静音/循环；提供「重试（重新生成一次，消耗重新计算）」与「参数微调后再生成」。

- 下载：保存到相册（写入权限不足时引导系统设置）。

- 分享：系统分享面板；分享【生成过程】短视频（录屏组合）可选，本版本仅分享成片。

- 消费规则（待商业化确认）：每日免费 1 次；超出后扣积分；VIP 不限量或固定额度。

### 4.8 我的生成（历史记录）

- 列表按时间倒序，展示首帧缩略图、状态、风格标签、生成时间、是否已下载。

- 支持单项删除与「清空成功记录」；已删除任务不可恢复。

- 生成中任务置顶展示。

### 4.9 控件与埋点

- 关键埋点：入口点击、选图成功/失败、指令输入（完成与放弃）、风格选择、提交成功/失败及原因、任务状态流转、预览播放率、下载/分享点击。

- 汇总报表：各状态任务分布、平均生成时长、错误率按原因拆解。

## 5. 非功能需求

### 5.1 性能

- 提交接口 P95 ≤ 1s；任务状态轮询 P95 ≤ 500ms。

- 生成时长目标：6 秒视频平均 90s 内完成（受队列影响，需压测确认）。

- 相册图片本地预检在 1s 内完成。

### 5.2 兼容性

- iOS ≥ 12.0、Android ≥ 8.0；主流机型（近 3 年出货）内存 ≥ 4GB 机型正常使用。

- 弱网（≤ 300kbps）下：轮询不中断，下载失败可重试，需提示网络状态。

- 断点续传/中断恢复：App 被杀后重启，任务状态应从服务端正确恢复。

### 5.3 安全与合规

- 生成内容需过服务端审核；涉及人脸时年龄识别与合规策略（原则：未成年人照片需监护人授权，本版本最低支持策略待法务确认）。

- 图片与生成任务数据加密传输（HTTPS）；图片仅用于本次生成，生成后按隐私策略保存（保存时长待定，默认 7 天）。

- 输入/输出内容进行敏感词过滤；违规内容展示统一提示语（文案待定）。

- 接口需限流防刷：单账号单日提交上限暂定 20 次（待定）。

## 6. 接口约定（摘要）

- `POST /v1/i2v/tasks`：提交生成任务（image、prompt、style、duration、ratio）。

- `GET /v1/i2v/tasks/{taskId}`：查询任务状态与结果（含审核状态）。

- `DELETE /v1/i2v/tasks/{taskId}`：取消排队中任务。

- `GET /v1/i2v/history?page=1&size=20`：生成历史（分页默认 20/页，上限待定）。

- `POST /v1/i2v/tasks/{taskId}/retry`：失败重试。

- 统一响应：`{ code, message, data }`；鉴权失败 401、额度不足 403 或 402、参数非法 400。

- 计费/权益统一走现有积分与 VIP 服务，本功能不单开计费接口。

## 7. 上线验收标准（示例）

- 端到端成功率 ≥ 90%（口径确认后按此验收）。

- 全机型冒烟：iOS/Android 各 Top3 机型生成-预览-下载全链路通过。

- 样式与异常测试：审核驳回、图片不合规、额度不足、超时、断网恢复等场景均已覆盖且提示正确。

- 埋点全部上线并可在报表查看。

## 8. 待确认项（需在开发前确认）

1. 免费额度：每日 1 次？VIP 与积分抵扣的具体数值与展示口径。
2. 生成时长与分辨率：6s/720P 默认是否可接受；输出档位成本测算。
3. 队列超时上限：10 分钟是否合理；超时后的补偿策略（退次数或积分）。
4. 审核策略：前置审核还是后置审核；平均审核时长；驳回占比基线。
5. 水印策略：免费/VIP 是否一致；水印位置与透明度。
6. 肖像是别与合规下限：肖像权确认弹窗的最小版本策略。
7. 图片与任务的隐私保留时长（拟 7 天，待法务确认）。
8. 「成功率 ≥ 90%」与「转化率 1.2 倍」的统计口径与验收基准。
