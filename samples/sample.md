# 用户中心登录模块 PRD（示例，含歧义点，供测试生成器验证）

版本：v1.0    负责人：张三    更新日期：2026-08-30

## 1. 概述

用户中心提供注册、登录、密码找回三个核心能力。本版本只描述 Web 端行为。

## 2. 登录

### 2.1 用户名密码登录

- 用户输入用户名与密码，点击「登录」提交。

- 登录成功后跳转到工作台首页。

- 登录失败时提示「用户名或密码错误」。

- 密码框支持软键盘可见性切换（小眼睛图标）。

- 若浏览器记住用户名，登录页自动填充上次用户名（需用户勾选「记住我」）。

### 2.2 验证码

- 密码连续输错后出现图形验证码。

- 验证码 4 位，大小写不敏感。

### 2.3 账号锁定

- 密码连续输错达到一定次数后锁定账号。

- 锁定后短时间内不允许登录。

## 3. 注册

- 手机号：11 位，大陆手机号段。

- 短信验证码：60 秒后允许重发。

- 密码规则：长度大于 6 位，包含字母与数字。

- 注册成功后自动登录并进入新手引导页。

## 4. 密码找回

- 通过手机号 + 短信验证码重置密码。

- 新密码规则与注册一致。

- 重置成功后需要重新登录。

## 5. 接口约定

- 登录接口：POST /api/auth/login，参数 username、password、captcha。

- 所有接口响应格式：{ code, message, data }。

- 会话有效期未定义，需与后端确认。
